# Natural Language Processing

Natural Language Processing (NLP) is a subfield of artificial intelligence and
computer science focused on enabling computers to understand, interpret, and
generate human language (text and speech). It combines computational
linguistics, machine learning, and deep learning to make sense of the structure,
meaning, and context of human communication.

**How it works (simplified pipeline):**

1. **Preprocessing** – raw text is cleaned: tokenization (splitting text into
   words/phrases), stop-word removal (dropping common words like "the," "is"),
   and lemmatization (reducing words to root form, e.g., "running" → "run").
2. **Analysis** – the system performs part-of-speech tagging, named entity
   recognition (identifying people, places, dates), and semantic analysis
   (deriving meaning from context).
3. **Representation** – words are converted into numerical vectors (word
   embeddings) that capture similarity and meaning.
4. **Output** – the model performs a task like classification, translation, or
   text generation.

**Two main subfields:**

- **Natural Language Understanding (NLU)** – interpreting input (intent,
  sentiment, entities).
- **Natural Language Generation (NLG)** – producing human-like text or speech.

**Common applications:** chatbots and voice assistants (e.g., Siri, Alexa),
machine translation, sentiment analysis, spam filtering, text summarization, and
large language models like ChatGPT.
